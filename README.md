# My Portfolio Website

This is my personal portfolio website, created to showcase my skills and projects as an IT student. I built this during my internship at Netlight Systems Ventures (March 3–April 14, 2025) to demonstrate my web development and hosting abilities.

[Live Demo](...)

## Features
- Responsive design for all devices using CSS media queries.
- Smooth scrolling with JavaScript for better navigation.
- Contact form integrated with Netlify Forms.
- Google Analytics to track user behavior (e.g., page views).
- Accessibility features like alt text for images.

## Technologies Used
- HTML, CSS, JavaScript
- CSS Flexbox for layouts
- Netlify for hosting
- Git/GitHub for version control
- Google Analytics for tracking
